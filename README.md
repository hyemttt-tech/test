# 🐍 스네이크 게임 (Snake Game)

Canvas 기반으로 제작된 클래식 **스네이크 게임**입니다.  
HTML, CSS, JavaScript가 하나의 파일에 통합되어 있어 바로 실행할 수 있습니다.

---

## 🎮 기능 소개

- 방향키로 뱀을 조종해 먹이를 먹으면 길어집니다.
- 벽 또는 자신의 몸과 충돌하면 게임 오버.
- **스페이스바** 또는 **시작 버튼**으로 게임 시작/일시정지.
- **R 키** 또는 **리셋 버튼**으로 재시작.
- 로컬 스토리지를 이용한 **최고 점수 저장 기능**.
- 반응형 Canvas UI 및 간단한 애니메이션 효과.
